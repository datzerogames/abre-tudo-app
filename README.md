# Abre Tudo

Leitor e organizador de documentos para Android, feito para o Brasil: PDF, Word, Excel, PowerPoint, fotos e muito mais.

**Seus arquivos não saem do aparelho.** O app funciona sem internet.

## Baixar

[Baixar o APK mais recente](https://github.com/datzerogames/abre-tudo-app/releases/latest/download/abre-tudo.apk)
